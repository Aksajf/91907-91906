INSTRUCTIONS FOR RUNNING THE PROGRAM

Step 1: Install the required libraries
This program uses a third-party library. Open your terminal or command prompt and run the following command to install it: pip install pygame

Step 2: Open the file named main.py
Ensure you have downloaded the entire project folder, including the assets directory and the leaderboard.txt file. Navigate into this folder on your computer and locate the main.py script.

Step 3: Run the program
From your terminal or command prompt, ensure you are in the directory where the file is located and type the following command to execute the game: python main.py or run the game thorugh idle.

Step 4: How to Play (Controls & Mechanics)
Once the main menu loads, follow the on-screen instructions to use the program. Use your Mouse to click on the "Play", "Leaderboard", or "Quit" buttons.

Movement: Use the W, A, S, D keys or the Arrow Keys to move your ship Left, Right, Up, and Down across the grid.
Shooting: Press the Spacebar to fire bullets at descending enemies and bosses.
Math Questions: Every 8 seconds, a math problem will appear on the screen. You have exactly 5 seconds to answer it.
Use the numbers to type your answer.
Press the Minus Sign if the answer calls for it.
Use Backspace to fix any typos.
Press Enter to submit your answer.

POWER-UPS & PENALTIES
If you answer a math question correctly before the timer runs out, you'll be granted one of five random power-ups to help you survive:
Fast Fire (Green): Increases your attack speed for 5 seconds.
Shield (Cyan): Grants a protective shield that absorbs one enemy hit.
MultiShot (Purple): Upgrades your weapon to fire three bullets simultaneously across three columns for 6 seconds.
Extra Life (Red): Adds 1 extra life to your health pool (up to a maximum of 5 lives).
Nuke (Orange): Instantly destroys all standard enemies on the screen and deals massive (8 HP) damage to the Boss.

Warning: If you submit the wrong answer or the 5-second timer runs out, you will receive an Attack Speed Down penalty, slowing your fire rate for 5 seconds.

SAVING YOUR SCORE
If you lose all your lives, let 3 enemies escape, or beat the final boss, you will be taken to the End Screen.
Type your name using alphabetic or numeric keys (up to 12 characters).
Press Enter to save your final score to the Leaderboard.
Press ESC to return to the Main Menu.
